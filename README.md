### 🚀 Highlighted Projects

#### 🔍 [The Search — Semantic Document Indexer](https://github.com/deepak-app/the_search)
A semantic search and document indexing pipeline built in Python.
- **Technologies:** `txtai`, `FAISS`, Python, SQLite
- **Features:** Auto-chunks diverse formats (`.txt`, `.md`, `.pdf`, `.docx`) with overlapping context. Implements cosine-similarity search.
- **MCP Server:** Exposes a Model Context Protocol interface, enabling AI agents to seamlessly run semantic queries over your local files.

#### 📊 [csv_analyzers — Data Story Analyzer](https://github.com/deepak-app/csv_analyzers)
A secure, client-side, provider-agnostic **Bring Your Own Key (BYOK)** data analysis application.
- **Technologies:** JavaScript (ES6+), Chart.js, HTML5/CSS3 (Glassmorphism), LocalStorage
- **Features:** Local columns-level statistical profiling (Pearson correlation, descriptive stats) to preserve raw data privacy. Fetches visual reports and data insights from LLM providers (Gemini, OpenAI, Anthropic) via direct client-side calls without exposing API credentials.
